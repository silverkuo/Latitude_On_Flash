================================================================================
 Dell Latitude ON Flash (2GB 內部模組) 喚醒工具包
================================================================================

【工具說明】
Dell Latitude E4310 筆電內部的 2GB Latitude ON Flash 實體模組（eUSB 儲存晶片），
在常規開機時，Dell BIOS 預設會切斷其供電。
當您使用任何「USB 隨身碟開機」（如 Lakka Live USB、Ubuntu Live USB 等）時，
磁碟列表中預設不會出現該 2GB 模組。

此工具透過 Dell 原廠 SMM Calling Interface（Class 17, Select 13, Arg 3），
直接向硬體發送通電信號，喚醒該 2GB 磁碟。

--------------------------------------------------------------------------------
【使用步驟】
--------------------------------------------------------------------------------
1. 將資料夾複製到開機隨身碟（或在 Live USB 系統中掛載隨身碟）。
2. 在 Live USB 的終端機（Terminal）中，切換到本資料夾：
     cd /opt/Dell/Latitude_ON_Flash
3. 執行一鍵喚醒腳本（需 root / sudo 權限）：
     sudo sh dell-wake.sh
4. 看到「SMI 回傳結果: ret=0」且終端機印出 2.0GB 磁碟（如 sdb 或 sdc）即代表通電成功。
5. 此時即可啟動安裝程式，將 OS 裝入該 2GB 內部模組。

--------------------------------------------------------------------------------
【檔案清單】
--------------------------------------------------------------------------------
- dell-wake.sh      : 喚醒 Shell 腳本（自動載入 dcdbas 驅動並執行喚醒）
- dell-wake         : 預編譯 C 語言二進位執行檔（支援 -rpath 原生動態庫搜尋）
- libsmbios_c.so.2  : Dell SMBIOS C 語言核心動態庫
- dell-wake.c       : 完整 C 語言原始碼（供自由審閱與二次編譯）
- Readme.txt        : 本說明手冊
